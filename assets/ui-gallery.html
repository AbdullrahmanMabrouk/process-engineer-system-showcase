1 · Stranding PDS - the repeating cage grid
The hardest layout in the application, and the one that forced four of the renderer's generic capabilities. Four cages repeat across the page. Tape dimension is one field holding two numbers.

2 · CV insulation - extruder zone matrix with variance colouring
Three extruders, each a ten-zone temperature profile recorded as set against actual. The colouring is the point: a cell flags only once it drifts past the block's tolerance, which for a temperature profile is ±5°. Below set reads blue, above set reads red, within tolerance stays plain. The same function colours the live form, the record list and the printed sheet, so all three agree.
